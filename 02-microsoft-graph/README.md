# Microsoft Graph

This section contains labs, notes, and automation projects using Microsoft Graph and the Microsoft Graph PowerShell SDK.

## Goals

- Learn Microsoft Graph API fundamentals
- Authenticate securely using Microsoft Graph
- Query and manage Microsoft Entra ID objects
- Automate common IAM administrative tasks

## Topics

- Graph Explorer
- Microsoft Graph PowerShell SDK
- REST API fundamentals
- Authentication and permissions
- Users and Groups
- Applications and Service Principals
- Reporting and automation

## Getting started

Start with **[SETUP.md](./SETUP.md)** — it walks through getting a free
Microsoft Entra ID tenant, installing PowerShell 7 and the Graph SDK, and
connecting. Do it once, then each exercise just runs.

## Folder structure

- **fundamentals** – Graph concepts and notes (Graph Explorer, REST, SDK, auth, permissions)
- **exercises** – Guided, numbered projects
  - `01-list-users` – First authenticated Graph call: list Entra ID users
